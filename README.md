## 这台机器到底给什么

MALIBU 是 DMIT 洛杉矶 Premium 系列的限量特价款，所在平台为 AN4，处理器是 AMD EPYC 9654。

| 项目 | 参数 |
| --- | --- |
| CPU | 1 vCPU（AMD EPYC 9654） |
| 内存 | 1.0 GB |
| 硬盘 | 20 GB SSD |
| 流量 | 1000 GB/月（双向计费） |
| 带宽 | 1 Gbps |
| IP | 1 IPv4 + 1 IPv6 /64 |
| 虚拟化 | KVM，VirtIO |
| 价格 | $49.9/年，无需优惠码 |

线路是这台机器的全部意义所在。三网回程统一走 CN2 GIA（AS4809）；去程电信和联通接 CN2，移动接 CMIN2（AS58807）。翻译成使用感受：不管你家用的是哪家宽带，从美国回国的这一段都走同一条精品线路，晚高峰不会出现白天测速好看、晚上掉到几百 K 的情况。第三方测评给出的洛杉矶到国内三网延迟在 150–180ms，这属于作者实测口径，官方没有承诺 SLA。

流量跑完不会停机，限速到 2Mbps 直到月底重置。2Mbps 大概够跑一个低码率音频流或纯文本 SSH，看视频就别想了。这个策略的好处是机器不会因为你某个月多跑了几百 G 就直接断网。

## 抢购当天会遇到的四件事，以及每件怎么处理

这一段按官方频道当天的原始回应整理，遇到同类情况可以照着做。

**1. 官网打不开，或者付完钱机器没激活。** 官方原话是可以稍晚再操作，产品当天会不限量供应。这种情况不用反复刷新下单，等系统恢复即可，重复下单只会制造更多待处理订单。

**2. 支付成功但后台显示未支付。** 先等支付网关回调，官方给的时限是“最多 12 小时”。超过 12 小时仍未回调，再开工单让客服手动处理。当天 08:08 和 08:10 官方两次更新说回调正在慢慢恢复、逐渐恢复中，说明这类延迟是系统侧的，不是你操作错了。

**3. 订单状态 Pending，但账单显示已付款。** 官方要求私聊邮箱，不走工单。这是当天针对这一类问题的专门处理通道。

**4. 机器出现多个 IP、没有 IPv6、始终报认证错误连不上。** 开工单后等待，官方明确说工单量大、处理慢，未开通的不用再发私信，会在半小时内逐步开通。这类故障最忌讳的是以为没买成又下一单。

系统的老毛病官方自己承认了，新计费系统什么时候全面上线没有时间表，只说“部分改善会在年底之前”。也就是说，下一次补货大概率还是这套流程，提前知道该等、该开工单、该私聊，比临场慌乱有用。

## 速度不理想时，官方给的排查顺序

2025 年 11 月 7 日，官方转发了一条针对“LAX Pro/EB 速率不理想”的回应，这段内容在前排文章里基本看不到，但对已经下单的人很有用。

官方的说法是：很多时候可能是用户所在运营商自身的限制，每个地区情况不同，实际用起来不理想属于正常，不能和亚太机器比；如果自己折腾过，要确认是不是调整过内核、用了 bbrplus 之类的加速、加了不确定是否会有反效果的 TCP 调优、或者使用了 UDP 协议。最后一句是“我们的带宽资源很充足，因此不需要担心是不是带宽资源紧张的问题导致的”。

按这个顺序自查：先把内核和拥塞控制恢复默认，再去掉所有 TCP 调优参数，然后检查 UDP 相关转发和代理协议，最后换一个运营商网络对比。四步走完还是慢，再考虑是不是线路本身在你所在地区的问题。官方同一段话里也说了，冲动下单后觉得速率一般，退款也没关系。
